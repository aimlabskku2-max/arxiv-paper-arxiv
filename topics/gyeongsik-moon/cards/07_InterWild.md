## Bringing Inputs to Shared Domains for 3D Interacting Hands Recovery in the Wild
- meta: arXiv 2303.13652 · 2023 · CVPR · Moon 단독 저자
- link: https://arxiv.org/abs/2303.13652
- short: InterWild
- problem: 대규모 모션 캡처(MoCap) 데이터셋 InterHand2.6M(IH2.6M)이 나온 뒤 3D 상호작용 손 복원 연구가 쏟아졌지만, 야외(in-the-wild, ITW) 강건성을 명시적으로 다룬 연구는 하나도 없었다. MoCap 데이터로 학습해 야외에서 테스트하면 결과가 불안정한데, 가장 대표적인 간극이 외형 간극(appearance gap)이다. IH2.6M 영상은 검은 배경과 인공 조명이라 야외 영상과 거리가 멀다. 근본 해법은 3D 정답이 달린 대규모 야외 데이터 수집이지만, 3D 캡처에는 보정·동기화된 수십 대의 카메라가 필요하고 이를 야외 곳곳에 설치하는 건 막대한 수작업이다. 게다가 상호작용하는 두 손은 심한 가림과 자기유사성 때문에 2D 수작업 주석조차 극히 어렵다. 결과적으로 대규모 야외 2D/3D 상호작용 손 데이터셋은 존재하지 않는다.
- naive: 야외 데이터셋에 이미 대규모로 존재하는 것은 2D "한 손" 데이터다. 그러니 3D 사람 복원에서 가장 지배적인 방식인 혼합 배치 학습(mixed-batch training)을 그대로 쓴다. 미니배치 절반은 MoCap 샘플로 3D 정답 완전 지도, 나머지 절반은 야외 샘플로 2D 정답 약지도. 약지도는 MANO 손 모델 덕에 가능하다. 메쉬에서 뽑은 3D 관절을 추정된 3D 전역 이동(global translation)과 고정된 가상 카메라 내부 파라미터로 2D에 투영해 정답 2D 좌표와 맞추면, 야외의 다양한 외형에 노출되어 일반화가 된다. 기존 3D 상호작용 손 복원 방법들을 이 방식으로 다시 학습시키기만 하면 될 것 같다.
- failure: 그런데 순진하게 재학습해도 강건해지지 않는다. 문제를 두 하위 문제 — (1) 좌·우 손 각각의 3D 메쉬 추정, (2) 두 손 사이의 3D 상대 이동(relative translation) 추정 — 으로 나누면 각각 다른 지점에서 깨진다. (1) 기존 방법들은 두 손이 상호작용할 때 "두 손이 함께 든 이미지"를 입력받는다. 그런데 야외 샘플은 대부분 한 손이므로, 혼합 배치 안에서 MoCap 쪽 두 손 이미지와 야외 쪽 한 손 이미지의 2D 손 크기 분포가 크게 어긋난다. 두 손이 한 이미지에 들어가면 손 하나의 2D 크기가 잘라낸 한 손 이미지보다 훨씬 작기 때문이다. 실제로 두 손 이미지를 쓰면 HIC의 MPVPE가 29.80/35.86인 반면 한 손 이미지는 15.65/15.70이다. (2) 두 번째 하위 문제는 야외 2D 약지도의 혜택을 거의 못 받는다. 오히려 해가 된다. 추정된 3D 전역 이동이 틀리면 상대 이동이 틀린 값으로 지도되는데, 단안 이미지에서 전역 이동을 맞히는 건 카메라 위치가 주어지지 않아 모호성이 크고 자주 틀린다. 결정적 차이는 손의 3D 크기가 MANO 형상 파라미터로 강하게 제약되는 반면(성인 손은 대개 15 cm 안팎), 상대 이동의 3D 크기는 거의 제약이 없다는 점이다 — 두 손은 상호작용 방식에 따라 얼마든지 가깝거나 멀 수 있다. 실험에서 2D 약지도를 켜면 TransNet 입력이 무엇이든 두 벤치마크 모두 MRRPE가 나빠진다(예: 2.5D 히트맵 31.35→61.05). 그렇다고 야외 약지도를 끄면 MoCap 영상만으로 학습되어 외형 간극 때문에 일반화가 실패한다(이미지 입력·약지도 없음: HIC 206.83).
- hypothesis: 문제는 손실 함수나 구조가 아니라, 두 데이터셋의 입력이 서로 다른 도메인에 놓여 있다는 것이다. 그러니 네트워크를 고치는 대신 입력을 공유 도메인(shared domain)으로 보내라. 하위 문제마다 어긋난 축이 다르므로 공유 도메인도 두 개다. (1)은 2D 크기 축이 어긋나 있으므로 공유 2D 스케일 공간으로, (2)는 색·조명 같은 외형 축이 어긋나 있으므로 외형 불변(appearance-invariant) 기하 특징 공간으로 보낸다. 상대 이동은 크기 제약이 약해 잘못된 약지도에 특히 취약하므로, 아예 2D 약지도를 받지 않고 MoCap의 3D 정답만으로 지도하되 입력을 외형 불변으로 만들어 일반화를 얻는다.
- method: DetectNet, SHNet, TransNet 세 부분으로 구성. (1) SHNet은 두 손이 상호작용하든 아니든 항상 잘라낸 한 손 이미지를 입력받아, 상호작용 손의 2D 크기를 한 손 이미지의 크기로 정규화한다. 손 크기 분포 그래프에서, 두 손 이미지 방식(기존)은 야외 한 손 분포와 크게 다른 반면 한 손 이미지 방식(제안)은 거의 같은 분포가 되어 설계를 정당화한다. 왼손 이미지는 좌우 반전해 항상 오른손으로 만들고 가중치를 공유하는데, 이는 손의 좌우성(handedness)까지 정규화하는 동시에 두 손이 심하게 겹쳐 좌·우 박스가 거의 같은 이미지를 낼 때 둘을 구분하게 해준다(논문 표현으로는 암묵적 가림 제거, implicit de-occlusion). 반전 없음/가중치 공유 15.80/17.36, 반전 없음/가중치 분리 15.34/16.96, 반전+공유(제안) 15.65/15.70. (2) TransNet은 이미지를 전혀 보지 않고 두 손의 2.5D 히트맵만 받는다. 2.5D 포즈에 2D 어파인 변환을 걸어 두 손 박스의 합집합 공간으로 옮겨 두 손 사이의 상대 2D 크기·이동을 얻고, 전역 평균 풀링 대신 손목 위치에서 이중선형 보간으로 손목 특징을 뽑아 상대 이동을 회귀한다. 상대 이동은 MoCap 데이터로만 지도한다. TransNet 입력별 MRRPE(HIC): 이미지 206.83, 이미지+2.5D 히트맵 54.36, 2D 히트맵 38.64, 2.5D 히트맵(제안) 31.35 — IH2.6M에서는 29.29로 비등하다. 즉 성능 차이가 야외 벤치마크에서만 크게 벌어진다는 점이 외형 간극 가설을 뒷받침한다. 특징 추출도 GAP 39.85, 전 관절 특징 48.99, 손목 특징 31.35. 최종 비교(HIC MPVPE / MRRPE): IHMR 30.76/46.38, 119.64 · Zhang 등 23.53/31.79, 110.25 · IntagHand 18.83/27.31, 52.46 · InterWild 15.65/15.70, 31.35. IH2.6M에서도 11.12/13.01, 29.29로 최고. 학습은 IH2.6M과 MSCOCO 전신 버전 혼합 배치, 주 평가셋은 학습에 쓰지 않은 HIC다. 한계로는 정면 뷰는 맞지만 다른 뷰에서 두 손 메쉬가 충돌하는 실패 사례를 들었다.
- pattern: (C). 새 데이터를 모으거나 새 구조를 세우는 대신, 이미 잘 되는 것들 — MoCap의 정확한 3D 정답과 야외의 대규모 2D 한 손 데이터 — 을 그대로 둔 채 입력 쪽을 두 개의 공유 도메인(2D 스케일, 외형 불변 기하 특징)으로 맞춰 붙였다. 야외 상호작용 손 데이터 수집이 사실상 불가능하다는 인식이 출발점이므로 (B)의 문제의식을 물려받되, 해법은 데이터를 만드는 대신 도메인을 맞추는 쪽이다.
